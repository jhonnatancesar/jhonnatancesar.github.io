## Por que vale a pena

<div class="grid cards" markdown>

-   :material-calendar-remove-outline:{ .lg .middle } **Você para de checar preço todo dia**

    Uma vez que você pede para acompanhar um produto, o trabalho de ficar voltando nas lojas passa a ser dele, não seu.

-   :material-chart-line:{ .lg .middle } **Ele sabe quando um preço realmente caiu**

    Como guarda o histórico do que já viu, consegue perceber uma queda de verdade — não só um número que parece baixo.

-   :fontawesome-brands-telegram:{ .lg .middle } **O aviso chega onde você já está**

    Direto no Telegram, sem mais um aplicativo para instalar ou lembrar de abrir.

</div>
