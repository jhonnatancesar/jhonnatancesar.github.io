# Começar a usar

## Em breve

Estamos preparando o AIShoppingAgent para ficar disponível para qualquer pessoa. Ainda não é possível acessar o bot a partir deste site.

Quando esse momento chegar, começar a usar vai ser simples assim: abrir uma conversa com o bot no Telegram e contar o que você quer acompanhar. Sem instalar nada, sem cadastro complicado — do mesmo jeito que está descrito em [Como funciona](como-funciona.md).

Enquanto isso, dá para conhecer tudo sobre o projeto navegando pelo site, ou acompanhar o andamento pelas [Novidades](novidades.md).
